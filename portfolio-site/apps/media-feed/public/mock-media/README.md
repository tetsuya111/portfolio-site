# モック用メディア

ポートフォリオで配信する media-feed のフィードに流すサンプル動画・ポスター画像を置くディレクトリ。S3 にはバックエンドがないため、モック（[../../mock/handlers.js](../../mock/handlers.js)）がこのディレクトリのファイルを指すコンテンツ一覧を返す。

## 置き方

1. 動画とポスター画像を手で用意し、このディレクトリに置く。既定のファイル名は `sample01.mp4`〜`sample03.mp4`、`sample01.jpg`〜`sample03.jpg`。
2. ファイル名・本数を変えたら、`handlers.js` の `MOCK_MEDIA` を合わせる。
3. `git lfs install` を済ませたうえでコミットする。拡張子ごとの対象は同ディレクトリの `.gitattributes` で指定している（`git lfs ls-files` で LFS に入ったか確認できる）。

## 注意

- このディレクトリの内容はすべて公開される。権利上問題のない素材（自作・フリー素材）だけを置き、実在のサービスのコンテンツは置かない。
- 縦長（例: 720x1280）・数秒〜十数秒・数 MB 以下にすると、フィードの見た目に近く、LFS の容量も抑えられる。
- ファイルがなくても画面は壊れず、動画が再生されないだけになる。
