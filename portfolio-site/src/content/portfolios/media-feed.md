複数の Web サイトからバッチで収集した動画・画像を、縦スワイプの短尺フィード形式で閲覧できる Web アプリケーション。収集したコンテンツをまとめた記事を作成でき、記事一覧は外部ブログに貼り付けられる埋め込み用 HTML（ブログパーツ）として書き出せる。

公開しているデモはフロントエンドだけを静的に配信したもので、API はブラウザ内のモックが応答する。フィードにはサンプル動画だけが流れ、ログイン・ブックマーク・記事などのデータを使う画面は空の状態で表示される。

## 構成

| ディレクトリ | 内容 |
| --- | --- |
| `backend/` | Django REST Framework による API（JWT 認証、SQLite、メディア配信）。収集・加工バッチも同じ Django プロジェクトの管理コマンドとして同梱 |
| `frontend/` | Next.js（App Router）・TypeScript・MUI による Web クライアント |

## 主な機能

### フィード

- 動画・画像を1件ずつ全画面で表示し、スワイプ・キー操作で次へ進む
- 種類（動画・画像）・タグ・キーワードでの絞り込み、ランダム表示
- シリーズ（関連コンテンツのまとまり）の前後への移動。表示順はシリーズごとの重みから事前に計算したキューで決める

### ユーザー機能

- ユーザー登録・ログイン（JWT 認証、トークンの自動更新）
- ブックマーク（まとめてダウンロード可能）・フォロー・コメント
- Cloudflare Turnstile による bot 対策

### 記事・ブログパーツ

- 収集したコンテンツをまとめた記事の作成・閲覧、記事タグ、サムネイルの自動生成
- 記事一覧を埋め込み用 HTML として生成する API と、HTML ファイルに書き出すバッチ

### バッチ処理

- 各サイトの API・HTML からコンテンツを収集する管理コマンド群
- 長い動画の短尺への分割、メディアの S3 への移行、表示順キューの再計算
- メディアの配信方式をアプリ経由・S3 の署名付き URL・CloudFront の署名付き URL から切り替え可能
