## Definition of Done

このスペック全体が完了したと言えるための条件。

- [ ] すべてのタスクが完了している
- [ ] マイグレーションを追加した場合は `python manage.py migrate` が通る
- [ ] フロントエンドを変更した場合は `npm run lint` と `npm run build` が通る
- [ ] `bash start.sh` で起動し、対象の画面・APIが実際に動くことを確認した
- [ ] requirements.mdの受け入れ基準をすべて満たしている
- [ ] design.mdの「セキュリティ・プライバシーへの影響」「パフォーマンス・スケーラビリティへの影響」で挙げた懸念に対応済み
- [ ] 関連ドキュメント（各 `readme.md`、CLAUDE.md、.kiro/steering/）の更新が必要な場合は反映済み
- [ ] `logs/` に作業ログを残した
