# チャット: 「要件の確定」ボタンを赤色にした

## 何を

`frontend/src/components/chat/ActionBar.tsx` の主要ボタン（`primary: true` = 「要件の確定」）の色を変更した。

- 変更前: `bg-stone-800 text-white hover:bg-stone-900`
- 変更後: `bg-red-600 text-white hover:bg-red-700`

## なぜ

ユーザーの指示による。5つのボタンの中で「要件の確定」だけが管理者への送信につながる操作のため、他と区別して目立たせる。

## 補足

- 白文字 + `red-600` はコントラスト比が十分で、文字が読めなくなることはない。
- 無効時の見え方（`disabled:opacity-40`）は他のボタンと共通のまま。
- 色だけで役割を伝えているわけではなく（ラベルが「要件の確定」）、色覚の違いによる区別の問題は生じない。

## 確認

`npm run lint` と `npx vitest run`（22件）がパス。ボタンの配色はテストでは検証していない（クラス名の検証は壊れやすいため、ラベルと無効化のみを検証する既存方針を維持）。
