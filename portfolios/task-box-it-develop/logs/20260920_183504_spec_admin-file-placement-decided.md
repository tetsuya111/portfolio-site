# 管理者リストのファイルの配置を確定

## 何を

`.kiro/specs/token-usage-and-history-retention/design.md` の未解決事項「管理者リストのファイルの配置場所」を確定し、データモデルに「管理者リストのファイルの配置」の節を追加した。tasks.md のタスク1・タスク8の完了条件にも反映した。

- 本番: コードのディレクトリの外（例: `/etc/task-box/admin_emails.txt`）に置き、`ADMIN_EMAILS_FILE` に絶対パスを設定する。
- 開発: 既定値 `BASE_DIR / "admin_emails.txt"`。`backend/.gitignore` に追加する。
- パーミッションは読み取りのみ（例: `0640`）。アプリは書き込まない。
- 相対パスは `BASE_DIR` 基準で解決し、カレントディレクトリに依存させない。
- `DEBUG=False` でパスが未設定、またはコードのディレクトリの内側を指す場合は `python manage.py check` で警告を出す（起動は止めない）。

## なぜ

ユーザーの指示（ベストプラクティスに従う）による。設定ファイルの一般的な扱い（コードと設定の分離、権限に関わる値をリポジトリに置かない、デプロイで消えない場所に置く）に従った。開発では既定値を残し、セットアップの手間を増やさないようにしている。

## 補足

- design.md の未解決事項に残るのは「バッチの定期実行をどこに置くか（インフラ決定待ち）」の1件のみになった。
