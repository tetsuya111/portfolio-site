# 概要
フリーランスエンジニアのポートフォリオサイトを作成する。

# 作成ディレクトリ
`portfolio-site/`以下
この指定をいかなる指定よりも優先する

# 要件
- ポートフォリオサイトを作成する
- 自分の経歴を含めた自己紹介の文章を記載できる
- ポートフォリオを動的に追加できる
- 記事を動的に追加できる

# 設計
- フロントエンドは`node/astro`を使用する
- cssは`tailwind`を使用する
- astroのフォルダ構成はベストプラクティスに従う
- README.mdを作成する
- 経歴や自己紹介を設定できる
  - mdファイルで管理し読み込む
  - サイト上からもmd設定できる。その際はmdファイルを更新する
- ポートフォリオを追加できるようにする
  - 追加する際はバッチコマンドなどを使用する
  - サイト上からは追加できない
- 記事を追加できるようにする
  - mdファイルを配置することで、量産的にできるよう追加できる
  - サイト上からもmdファイルにより動的に追加できる
- AWS上に作成できるように以下「AWS関連」の設計でファイルを作成する
## AWS関連
- cloud formation でスタックを作成し、構成する
- S3/cloud front を使用し配信する
- ACMを設定する
- route 53を使用しドメインを設定する
- CIとしてcode build と githubを連携しテストできるようにする

## ポートフォリオの表示
### 概要
ポートフォリオの情報を表示する。`portfolios/`以下の情報は直接扱わない。
### ページ
- メインページ
### データ
md形式のファイルで管理する。
- タイトル
- 内容
- タグ 
  - many
- URL
### 設計
- タイル形式で表示する
  - タイトルとタグを表示する
  - URLが存在する場合はタイル内に小さい「ポートフォリオのURL」に遷移するボタンを作成
- クリックすると、ポートフォリオのメインページを表示する
- `portfolio-site/`より下（何階層でもいい）のディレクトリに関連データは保存する
#### メインページ
- タイトル、内容、タグを表示する
  - タイトルとタグはDBのデータを使用する
  - 内容はmd形式を想定し読み込む
