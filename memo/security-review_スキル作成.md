# 概要
セキュリティレビューができるスキルを作成したい。
trailofbits関連のスキルがたくさんあるので統合的にそのスキルを使用できるスキルを作成したい。
呼びだすスキルは用途に応じてベストプラクティスや公式ドキュメントに従い任意で選定し作成する。

それぞれのスキルの活用し、詳細にレビューする。
