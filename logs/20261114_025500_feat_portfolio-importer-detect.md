# 機能: ポートフォリオ取り込みコマンドのフロントエンド・バックエンド検出

## 何を

- `importer/detect.py` を追加した。`frontend/`・`web/`・`client/`・ルートから node 製フロントエンドを、`backend/`・`server/`・`api/`・ルートから Python / node 製バックエンドを検出する。
- フロントエンドは Vite・Astro・静的出力設定のある Next.js だけを配信可能と判定し、それ以外は理由を返す。検出した技術はタグ候補として返す。

## なぜ

- S3 で配信できないアプリを登録してデプロイ全体を止めないため（要件 R2-1, R2-2, R3-1）。
