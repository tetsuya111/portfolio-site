# 機能: ポートフォリオ取り込みコマンドの本体

## 何を

- `importer/cli.py` と入口 `add_portfolio.py` を実装した。コピー → 検出 → フロントエンド登録 → Dockerfile 生成（`--build-image` 時のみイメージ作成） → 掲載 md 作成を順に行い、結果を JSON で出力する。エラー時は理由を標準エラーに出して終了コード 1。
- `--site-url` 指定かつフロントエンドを配信登録した場合、掲載 md の URL を `<サイトURL>/apps/<スラッグ>/` にする。

## なぜ

- スキルから1コマンドで取り込みを実行し、結果を機械的に読めるようにするため（要件 R5-1, N1, N3）。
