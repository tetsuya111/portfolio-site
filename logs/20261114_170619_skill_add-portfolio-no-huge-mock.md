# スキル /add-portfolio に「無理に膨大なモック処理を作らない」を明記

## 何を

`.claude/skills/add-portfolio/SKILL.md` を次のように変えた。

- 「モックの仕上げ」に、無理に膨大なモック処理を作らないことを明記した。
  - DB・検索・認証・状態の保存などのバックエンドの処理は、モックで再現しない。
  - 書く量が多くなる箇所は 404 のままにし、報告に書く。
- 「よくある間違い」の表の該当行に、膨大なモックを作ることを加えた。

## なぜ

ユーザーの指示による。正確なデータより 404 で答えることを優先する方針（`20261114_170449_feat_add-portfolio-mock-default-404.md`）を、スキルの手順でも守らせるため。
