# モック接続のコードレビュー指摘に対応

- 何を: ランタイムで不正な % エスケープを例外にしない／固定の区間がないルート（`/`・`/:slug`）を雛形に書かず警告／node のルート検出から HTTP クライアントの呼び出しとバックエンド配下のフロントエンドを除外／handlers.js を書いてから apps.json に `mock: true` を書く順に変更／`__mock__` の除外判定に区切り文字を付与／HTML 文書でないファイルには差し込まない／`add_portfolio.py` の使い方から `--build-image` を削除。
- なぜ: `code-review`（1周目）の指摘のうち、実コードで妥当と確認したもの。router の prefix の解決はスキルで確認する設計のため対応しない。
